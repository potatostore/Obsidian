# API 요청 형식 변경은 프론트와 먼저 합의하기

## 상황
- 코드 리뷰를 하다가, request parameter를 Map으로 받는 부분을 DTO로 바꾸고 싶었다 — [[2026-09-16]]

## 한 일
- 프론트에서도 Map으로 요청을 보내고 있다면 혼자 바꿨을 때 전체적으로 오류가 날 수 있다고 판단해서, 바로 바꾸지 않았다

## 배운 점
