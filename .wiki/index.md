# 위키 인덱스

## 허브
- [[대학생활]] — 최상위 지도: 학업·전공 지식·프로젝트·경험
- [[학업]] — 학기별(2-1 ~ 3-2) 수강 과목 20개
- [[전공 지식]] — 영역 지도 9개로 가는 입구
- [[알고리즘 지도]] — 알고리즘 노트 약 70개를 기법별로 묶음 + 알고리즘 수업·코드트리
- [[자료구조 지도]] — 자료구조 노트 15개 + 컴퓨터 자료구조 수업
- [[컴퓨터 시스템 지도]] — 컴퓨터구조·논리회로·OS·시스템 프로그래밍·RTS 수업, OS·Memory 개념
- [[네트워크 지도]] — 컴퓨터 네트워크·유비쿼터스 수업 (개념 페이지 아직 없음)
- [[데이터베이스 지도]] — DB·파일처리론 수업, DB·ORM·SQL 개념, MongoDB·Redis·Flyway
- [[데이터·AI 지도]] — 빅데이터 수업, 머신러닝 알고리즘 6개
- [[수학 지도]] — 선형대수학, 컴퓨터 그래픽스
- [[프로그래밍·설계 지도]] — 언어 6개, 객체지향·컴퓨터실험2 수업, 설계 도서
- [[백엔드·인프라 지도]] — 백엔드 구조, Spring·Docker·K8s·CI/CD·모니터링, AWS 노트
- [[프로젝트]] — ShoppingMall·NIMDA·Unreal 등 프로젝트와 해커톤·교육 활동
- [[경험]] — 일지·트러블슈팅에서 뽑은 교훈 (아직 비어 있음)
- [[Calendar]] — 날짜 노트 111개를 연도 허브(2024·2025·2026)로 묶음 (자동 생성)
