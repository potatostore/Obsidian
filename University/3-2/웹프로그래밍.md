# 3장. HTML 기본 문서 만들기

## 3-1 웹 개발과 HTML

### 웹 개발이란

#### 서버와 클라이언트
- **클라이언트**: 사용자가 웹 사이트에 접근할 때 사용하는 기기. 좁은 의미로는 웹 브라우저
- **서버**: 인터넷에 연결된 컴퓨터. 웹 요소와 여러 정보가 저장됨

#### 프런트엔드 개발과 백엔드 개발
- **프런트엔드**: 웹 브라우저 화면에 보이는 부분을 다룸 → 웹 사이트 제작. HTML, CSS, 자바스크립트 사용
- **백엔드**: 사용자 뒤(back)에서 보이지 않는 영역, 즉 서버를 다룸. 데이터베이스 설계, 데이터 처리. 자바, PHP, 파이썬 등 사용

### HTML이란

#### HTML의 뜻
- **H**yper **T**ext **M**arkup **L**anguage
- Hyper Text: 웹에서 자유롭게 오갈 수 있는 링크
- Markup: 텍스트뿐 아니라 이미지, 영상 등을 표시함
- ==HTML은 웹에서 자유롭게 오갈 수 있는 웹 문서를 만드는 언어==

#### 태그
- 마크업에 사용하는 꼬리표를 **태그(tag)** 라고 함
- 여는 태그와 닫는 태그 사이에 내용을 넣음 (예: h1 여는 태그 + 제목 + h1 닫는 태그)

## 3-2 HTML 문서의 구조

### 기본 구조

#### 기본 문서 (index.html)
~~~html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>HTML 기본 문서</title>
</head>
<body>
  <h1>프런트엔드 웹 개발</h1>
  <hr>
  <p>HTML</p>
  <p>CSS</p>
  <p>자바스크립트</p>
</body>
</html>
~~~
- 크게 **DOCTYPE 선언 → html → (head + body)** 순서로 감쌈

#### DOCTYPE 선언
- !DOCTYPE html (소문자 !doctype html도 가능)
- 웹 브라우저에게 "이제부터 처리할 문서는 HTML(HTML5) 문서"라고 알려 줌

#### html 태그
- 웹 문서의 시작과 끝을 표시. 브라우저는 html 태그를 만나면 닫는 태그까지 읽어 화면에 표시
- **lang 속성**으로 문서에서 사용할 언어 지정 (예: lang="ko")
- 문서 정보를 담는 **head**와 문서 내용을 담는 **body**를 포함

#### head 태그
- 브라우저에게 문서 관련 정보를 줌
- ==웹 브라우저 화면에는 보이지 않음==
- 문서에서 사용할 외부 파일(CSS 등)을 링크

#### meta 태그
- 문자 세트 등 문서 정보를 지정
- 한글을 표시하려면 **charset="UTF-8"** 사용
- name / content 쌍으로 다양한 정보 지정
  - name="keywords": 웹 문서의 키워드
  - name="description": 웹 문서의 설명
  - name="author": 웹 문서의 소유자나 제작자

#### title 태그
- 문서 제목. 브라우저 **탭**에 표시되는 내용

#### body 태그
- 실제 브라우저 화면에 표시될 내용
- 대부분의 태그는 body 안에서 사용

### 기본 텍스트 태그

#### 제목 h1 ~ h6
- 제목(heading). 크기는 h1 > h2 > h3 > h4 > h5 > h6

#### hr 태그
- 주제가 바뀔 때 쓰는 **수평 가로선**. 닫는 태그 없음

#### p 태그
- 문단(paragraph)을 정의
- HTML5에서는 p 태그의 **align 속성**(left, right, center, justify)을 더 이상 지원하지 않음 → 정렬은 CSS로

## 3-4 웹 문서 구조를 만드는 시맨틱 태그

### 시맨틱 태그란

#### 의미
- 시맨틱(semantic) = 의미론적인, 의미가 통하는
- ==이름만 봐도 의미를 알 수 있는 HTML 태그==

#### 사용하는 이유
- 화면 낭독기 같은 보조 기기가 사이트 구조를 이해할 수 있음
- 문서 구조가 정확히 나뉘어 PC, 모바일 등 다양한 화면에서 표현하기 쉬움
- 검색할 때 필요한 내용을 정확히 찾을 수 있음

### 시맨틱 태그 종류

#### header
- 헤더 영역. 사이트 전체의 헤더 또는 특정 영역의 헤더
- 검색 창이나 사이트 메뉴 삽입
- ==head 태그와 다름==: header는 **body 안**에 있는 화면 영역, head는 화면에 안 보이는 문서 정보

#### nav
- 내비게이션(메뉴) 영역
- 문서 위치에 영향을 받지 않음
- 문서 안에 여러 개 만들 수 있음 (id로 구분)

#### main
- 웹 문서의 핵심 내용. 문서마다 다르게 보여 주는 내용으로 구성
- ==웹 문서에서 한 번만 사용==

#### article
- 독립된 콘텐츠 항목 (따로 떼어 내도 콘텐츠가 되는 내용)
- section 태그를 포함할 수 있음

#### section
- 콘텐츠 영역. 몇 개의 콘텐츠를 묶는 용도
- ==CSS 적용을 위해 묶는 용도로 쓰지 말 것== → 그럴 때는 div

#### aside
- 본문 외에 왼쪽, 오른쪽, 아래쪽에 표시하는 사이드 바
- 필수 요소가 아니므로 필요할 때만 사용

#### footer
- 사이트 제작 정보, 저작권 정보, 연락처 등
- 다른 시맨틱 태그를 넣어 다양한 정보 포함 가능

#### div
- 시맨틱 태그가 아닌, 여러 소스를 묶는 용도
- 영역을 구별하거나 스타일을 적용하기 위해 사용

### 예제: structure.html

#### 페이지 뼈대
~~~html
<div id="container">
  <header>
    <div id="logo"><a href="index-footer.html"><h1>Dream Jeju</h1></a></div>
    <nav>
      <ul id="topMenu">
        <li><a href="#">단체 여행</a></li>
        <li><a href="#">맞춤 여행</a></li>
      </ul>
    </nav>
  </header>
  <main class="contents">
    <section id="headling">
      <h2>몸과 마음이 치유되는 섬</h2>
      <div class="detail"> ... </div>
    </section>
  </main>
  <footer>
    <section id="bottomMenu"> ... </section>
  </footer>
</div>
~~~
- 전체를 div로 묶고, 그 안을 header(로고 + nav) → main(section 여러 개) → footer로 나눔
- 외부 CSS는 head 안에서 link 태그로 연결 (rel="stylesheet" href="css/structure.css")

### a 태그 기초

#### a 태그와 href 속성
- anchor의 첫 글자 ('정박지', '닻'이라는 뜻)
- 다른 문서로 이동하거나 같은 문서 안에서 이동할 때 사용
- **href 속성**에 링크할 페이지의 URL을 적음

#### href 속성값 4가지
| 종류 | 예 |
| --- | --- |
| 절대 주소 (absolute URL) | href="http://www.tcpschool.com/index.php" |
| 상대 주소 (relative URL) | href="/lecture/logo.png" |
| 같은 페이지 안의 id 요소 | href="&#35;bottom" |
| 스크립트 | href="javascript:alert('반갑습니다!')" |

#### href="#"
- 이벤트가 발생하기 전에 화면 최상단으로 이동한 뒤 이벤트를 수행
- 아직 연결할 주소가 없는 메뉴 링크 자리에 임시로 씀 (structure.html의 메뉴들)

# 4장. 다양한 내용 입력하기

## 4-1 텍스트 태그

### 제목과 단락

#### hn 태그
- 제목 표시. 기본형은 hn 여는 태그 + 제목 + 닫는 태그 (n = 1 ~ 6)

#### p 태그
- 텍스트 단락. 입력한 내용 앞뒤로 빈 줄이 생기면서 단락이 만들어짐

#### br 태그
- 줄 바꾸기. 줄을 바꿀 위치에 넣음
- ==닫는 태그가 없음==

#### blockquote 태그
- 인용문. 다른 텍스트보다 안으로 들여 써짐

### 텍스트 강조

#### strong과 b (굵게)
- **strong**: 중요한 내용이라서 강조해야 할 때
- **b**: 단순히 굵게 표시할 때

#### em, i, cite (이탤릭)
- **em**: 흐름상 특정 부분을 강조하고 싶을 때
- **i**: 단순히 이탤릭체로 표시할 때
- **cite**: 책, 영화, 블로그 같은 저작물의 제목 표시
- ==모양은 같아도 의미가 다름== (strong/em은 의미 강조, b/i는 모양만)

#### sup, sub, ins, del
- 예제 sub_sup_ins_del.html에 나온 태그 (보충: 각 의미)
  - sup: 위 첨자 (혈액순환¹)
  - sub: 아래 첨자
  - ins: 새로 삽입된 내용 (밑줄)
  - del: 삭제된 내용 (취소선)

## 4-2 목록 만들기

### 순서 목록

#### ol, li 태그
- 각 항목 앞에 **숫자**가 붙음
~~~html
<ol>
  <li>샐러드 채소를 씻고 물기를 제거한 후 준비합니다.</li>
  <li>레드향과 아보카도, 토마토를 먹기 좋은 크기로 썰어둡니다.</li>
</ol>
~~~

#### type, start 속성
- **type**: 숫자 모양 (1: 숫자, a: 소문자, A: 대문자, i: 로마 소문자, I: 로마 대문자)
- **start**: 목록의 시작 번호

### 순서 없는 목록

#### ul, li 태그
- 각 항목 앞에 **불릿**이 붙음
- 쓰는 방법은 ol과 같고 바깥 태그만 ul

### 설명 목록

#### dl, dt, dd 태그
- '이름(제목)'과 '값(설명)' 형태의 목록
- **dl** (Description List): 설명 목록 전체를 감싸는 컨테이너
- **dt** (Description Term): 정의할 용어나 제목
- **dd**: 그 용어에 대한 설명 (슬라이드 표기는 Description Description, 보충: 표준 명칭은 description details)
~~~html
<dl>
  <dt>선물용 3kg</dt>
  <dd>소과 13~16과</dd>
  <dd>중과 10~12과</dd>
</dl>
~~~

#### 특징
- dl 안에 dt와 dd 쌍이 하나 이상 들어감
- ==하나의 dt에 여러 dd를 쓸 수 있고, 그 반대도 가능==
- 브라우저 기본 스타일로 dd에 들여쓰기가 적용됨

#### 활용 사례
- FAQ: 질문(dt)과 답변(dd)
- 사전, 용어집: 용어(dt)와 정의(dd)
- 메타데이터: 이름(dt)과 값(dd) (회원 정보, 상품 특징 등)

## 4-3 표 만들기

### 표의 구성 요소

#### 표를 만드는 태그
| 태그 | 역할 |
| --- | --- |
| table | 표 전체 |
| caption | 표 제목 |
| tr | 행 (table row) |
| th | 제목 셀 (table header) |
| td | 일반 셀 (table data) |

### 표의 구조 정의

#### thead, tbody, tfoot
- 표를 제목(thead), 본문(tbody), 요약(tfoot)으로 나눔
- 화면에는 보이지 않지만 화면 낭독기나 자바스크립트가 읽을 수 있음 → 시각 장애인도 표 구조를 쉽게 이해
- 본문이 길면 자바스크립트로 제목과 바닥을 고정하고 본문만 스크롤되게 할 수 있음

### 셀 합치기

#### rowspan
- **행(세로 방향)** 합치기: td rowspan="합칠 셀의 개수"
- 합쳐진 셀이 아래 행 자리까지 차지하므로, ==아래 행에서는 그 칸의 td를 빼고 적음==

#### colspan
- **열(가로 방향)** 합치기: td colspan="합칠 셀의 개수"

#### 예제 (table-3exe.html)
~~~html
<tbody>
  <tr>
    <td rowspan="2">선물용</td>
    <td>3kg</td> <td>11~16과</td> <td>35,000원</td>
  </tr>
  <tr>
    <td>5kg</td> <td>18~26과</td> <td>52,000원</td>
  </tr>
</tbody>
~~~
- 두 번째 tr에는 '선물용' 칸이 없음 (위에서 rowspan으로 합쳤기 때문)

### 열 묶기

#### colgroup, col
- 완성 예제(poster)에 나온 태그. colgroup 안의 col 하나가 열 하나에 대응
- col에 style을 주면 그 열 전체에 배경색, 너비 등이 적용됨 (예: 첫 열만 회색 배경, 3·4열 너비 150px)

## 4-4 이미지 삽입하기

### img 태그

#### 기본형
- img src="이미지 파일 경로" alt="대체용 텍스트"
- 닫는 태그 없음 (보충)

#### src 속성
- ==웹 문서 파일의 위치를 기준으로== 이미지 경로 지정
- 같은 폴더면 파일 이름만 (src="tangerines.jpg")
- 하위 폴더면 폴더까지 (src="images/tangerines.jpg")

#### alt 속성
- 이미지를 설명하는 대체 텍스트
- 화면 낭독기가 이미지 대신 읽어 줌 → **웹 접근성**
- 이미지를 표시할 수 없을 때 대신 표시됨
- 텍스트를 이미지로 만들었다면 그 내용을 alt에 그대로 넣음
- 불릿 이미지나 작은 아이콘은 alt=" " 처럼 비워 둠

#### width, height 속성
- 이미지 크기 조정. 퍼센트(width="50%")나 픽셀(width="150") 사용
- ==둘 중 하나만 지정하면 나머지는 비율에 맞게 자동 계산==

### 웹에서 쓰는 이미지 형식

#### GIF, JPG, PNG
| 형식 | 특징 |
| --- | --- |
| GIF | 색상 최대 256가지, 파일 크기가 작아 아이콘·불릿 등 작은 이미지에 사용 |
| JPG/JPEG | GIF보다 색상과 명암을 다양하게 표현. 수정·저장을 반복하면 화질이 떨어질 수 있음 |
| PNG | 네트워크용으로 개발. 색상을 다양하게 표현하면서 ==투명한 배경== 가능 → 웹에서 가장 많이 사용 |

### 설명글 붙이기

#### figure, figcaption
- **figure**: 도표, 일러스트, 이미지, 소스 코드 등 독립된 콘텐츠를 묶음. table이나 img를 대신하는 게 아니라 문서의 다른 내용과 구별된다는 표시
- **figcaption**: 설명글(캡션). figure 안에서 함께 사용
~~~html
<figure>
  <img src="images/spring.png" alt="제주의 봄">
  <figcaption>가장 먼저 봄을 맞이하는 제주도</figcaption>
</figure>
~~~

### srcset 속성

#### 개념
- 여러 이미지 정보를 한꺼번에 알려 주고, 화면 너비나 해상도에 따라 알맞은 이미지를 표시
- 기본형: img src="기본 이미지" srcset="파일1, 파일2, ..." alt="대체 텍스트"

#### w 서술자
- '파일 이름 너비w' 형식. w는 이미지 파일의 너비
~~~html
<img src="baloon.png" srcset="small.png 700w, large.png 1000w" alt="하늘 위로 올라가는 풍선">
~~~

#### x 서술자
- x는 장치의 **픽셀 비율**. 값이 클수록 고화질 이미지를 연결
~~~html
<img src="sky.png" srcset="sky-1.png 1x, sky-2.png 2x" alt="파란 하늘 사진">
~~~

## 4-5 오디오와 비디오 삽입하기

### object와 embed

#### object 태그
- 음악뿐 아니라 동영상, 자바 애플릿, PDF 등 다양한 개체 삽입
- 기본형: object width="너비" height="높이" data="파일"
  - **data**: 재생할 파일, **width/height**: 플레이어 크기
- 예: PDF 삽입 (data="product.pdf")

#### embed 태그
- 대부분의 브라우저에서 사용 가능한 멀티미디어 삽입 태그
- 기본형: embed src="파일 경로" width="너비" height="높이"
- ==닫는 태그 없음==, 파일은 **src**로 지정 (object는 data)

### 지원하는 파일 형식

#### 멀티미디어 파일 종류
| 종류 | 확장자 | 설명 |
| --- | --- | --- |
| 비디오 | mp4 | 가장 많이 쓰는 형식. 라이선스가 있지만 웹에서는 무료 |
| 비디오 | webm | 화질이 우수하면서도 무료라 mp4와 함께 많이 사용 |
| 오디오 | mp3 | 대부분의 음원 형식. 2017년 이후 라이선스가 종료되어 무료 |
| 오디오 | mp4/m4a | mp3의 문제점을 개선한 AAC 코덱 사용 |

#### 브라우저별 지원
- mp3, mp4는 주요 브라우저 대부분이 지원
- webm은 인터넷 익스플로러, 사파리, iOS 사파리, 안드로이드 브라우저에서 미지원 (크롬, 파이어폭스, 오페라는 지원)

### audio와 video 태그

#### 기본형
~~~html
<audio src="medias/spring.mp3" controls></audio>
<video src="medias/salad.mp4" controls width="700"></video>
~~~
- controls가 없으면 재생 막대가 안 보여서 재생할 방법이 없음 (보충)

#### 속성
| 속성 | 설명 |
| --- | --- |
| controls | 플레이어에 컨트롤 바 표시 |
| autoplay | 자동 실행 |
| loop | 반복 재생 |
| muted | 소리 제거 |
| preload | 페이지를 불러올 때 파일을 어떻게 로딩할지 지정 (auto, metadata, none / 기본값 auto) |
| width, height | 비디오 플레이어 크기. 하나만 지정하면 나머지는 자동 계산 |
| poster="파일 이름" | video 전용. 재생 전까지 표시할 포스터(썸네일) 이미지 |

#### 썸네일(포스터) 이미지
- 컨트롤 막대와 함께 비디오를 넣으면 재생 전까지 검은 화면만 보임
- poster 속성으로 재생 전까지 이미지를 보여 줌

#### 자동 재생 규칙
- 웹 접근성 지침: 멀티미디어를 사용자 동의 없이 시작하지 않도록 권고
- 최신 브라우저는 소리가 있는 미디어의 자동 재생을 막음
- ==autoplay는 muted와 함께 써야 동작== (크롬, 파이어폭스), loop를 더하면 계속 반복
~~~html
<video src="medias/salad.mp4" width="700" autoplay muted loop></video>
~~~

## 4-6 하이퍼링크 삽입하기

### a 태그

#### 기본형
- a href="링크할 주소" + 텍스트 또는 이미지 + a 닫는 태그
- 다른 문서나 다른 사이트로 바로 연결

#### 텍스트 링크와 이미지 링크
~~~html
<a href="order.html" target="_blank">주문서 작성하기</a>

<a href="order.html">
  <img src="images/tangerines.jpg" alt="레드향">
</a>
~~~
- 텍스트 링크는 밑줄이 생기고, 이미지 링크는 마우스 포인터가 손 모양으로 바뀜

#### target 속성
- target="_blank": 연결된 문서를 **새 탭**으로 엶
- 슬라이드 설명에는 "blank"로 적혀 있지만 코드 예제와 표준 값은 ==_blank== (밑줄 포함)

### 한 페이지 안에서 점프하는 앵커

#### 만드는 방법
1. 이동하고 싶은 위치의 태그에 **id 속성**으로 앵커 이름을 붙임 (==앵커 이름은 중복 불가==)
2. a 태그의 href에서 이름 앞에 # 기호를 붙여 링크

#### 예
- 이동할 위치: h2 태그에 id="recipe"
- 링크: a 태그에 href="&#35;recipe"
- 목차 링크를 클릭하면 해당 id가 붙은 제목 위치로 스크롤됨

# 5장. 입력 양식 작성하기

## 5-1 폼 삽입하기

### 폼이란

#### 웹에서 만나는 폼
- 사용자가 웹 사이트로 정보를 보낼 수 있는 요소는 모두 폼(form)
- 폼 작업은 대부분 정보를 저장, 검색, 수정하는 일 → 데이터베이스 기반
- ==폼의 모양은 HTML 태그가 만들고, 입력한 정보 처리는 서버 프로그래밍(ASP, PHP 등)이 담당==

### form 태그

#### 기본형
- form 여는 태그와 닫는 태그 사이에 여러 폼 요소를 넣음
~~~html
<form action="register.php">
  <!-- 여러 가지 폼 요소 -->
</form>
~~~
- 위 예: 폼 내용을 서버로 전송하면 서버의 register.php가 실행됨

#### form 태그의 속성
| 속성 | 설명 |
| --- | --- |
| method | 입력 내용을 서버 프로그램으로 넘기는 방식. get 또는 post |
| name | 자바스크립트로 폼을 제어할 때 쓸 폼 이름 |
| action | 폼 내용을 처리할 서버 프로그램 지정 |
| target | action의 스크립트 파일을 현재 창이 아닌 다른 위치에서 열도록 함 |

#### get과 post
- **get**: 데이터를 256 ~ 4,096byte까지만 넘길 수 있음. ==주소 표시줄에 입력 내용이 그대로 드러남==
- **post**: 길이 제한이 없고 입력 내용이 드러나지 않음 → 로그인처럼 민감한 정보에 사용

### fieldset과 legend

#### fieldset 태그
- 폼 요소를 **그룹으로 묶음** (예: '상품 선택', '배송 정보')

#### legend 태그
- fieldset으로 묶은 그룹에 **제목**을 붙임
~~~html
<fieldset>
  <legend>상품 선택</legend>
  ...
</fieldset>
~~~

### label 태그

#### 역할
- input 같은 폼 요소에 이름표(레이블)를 붙임
- ==레이블을 클릭해도 연결된 요소가 선택됨== (text는 입력 상태, checkbox/radio는 체크·해제) → 클릭 영역이 텍스트까지 확장

#### 연결 방법 2가지
~~~html
<!-- 1) label 안에 input 넣기 -->
<label>아이디(6자 이상)<input type="text"></label>

<!-- 2) 따로 쓰고 for와 id로 연결 -->
<label for="user-id">아이디(6자 이상)</label>
<input type="text" id="user-id">
~~~
- 2번 방식은 ==label의 for 값과 input의 id 값이 같아야== 연결됨

### id, class, name 비교

#### id 속성
- 요소를 고유하게 식별하는 이름. ==한 문서에서 중복 불가==
- 쓰임: CSS 스타일, 자바스크립트 DOM 조작, 앵커 링크(페이지 내 이동)
  - CSS: &#35;unique-name { color: red; }
  - 자바스크립트: document.getElementById('unique-name')
  - 앵커: a 태그에 href="&#35;unique-name"
- 명명 규칙: 공백 불가, 문자로 시작

#### 세 속성 비교
| 속성 | 목적 |
| --- | --- |
| id | 고유한 식별 (요소 하나에만) |
| class | CSS 선택 및 재사용 (반복되는 요소에) |
| name | 폼 요소의 값(value)을 **서버로 전송**하기 위해 필요 |

## 5-2 사용자 입력을 위한 input 태그

### input 태그 개요

#### 특징
- 사용자에게 입력을 받는 입력 필드를 정의. 주로 form 안에서 사용
- **type 속성값**에 따라 여러 모양으로 바뀜
- ==빈 태그(empty tag)==: 닫는 태그 없이 속성만 가짐
- label로 이름표를 붙일 수 있음

#### type 한눈에 보기
| type | 설명 |
| --- | --- |
| text | 한 줄 텍스트 박스 |
| password | 비밀번호 입력 필드 |
| search | 검색 필드 |
| url | URL 주소 필드 |
| email | 이메일 주소 필드 |
| tel | 전화번호 필드 |
| checkbox | 여러 항목 중 2개 이상 선택 |
| radio | 여러 항목 중 1개만 선택 |
| number | 숫자를 조절하는 스핀 박스 |
| range | 숫자를 조절하는 슬라이드 막대 |
| date | 날짜 (연, 월, 일) |
| month | 날짜 (연, 월) |
| week | 날짜 (연, 주) |
| time | 시간 (시, 분, 초, 분할 초) |
| datetime | UTC 기준 날짜와 시간 |
| datetime-local | 사용자 지역 기준 날짜와 시간 |
| submit | 전송 버튼 |
| reset | 리셋 버튼 |
| image | submit 대신 쓰는 이미지 버튼 |
| button | 일반 버튼 |
| file | 파일 첨부 버튼 |
| hidden | 화면에 안 보이지만 서버로 넘기는 값 |

### 텍스트 입력 필드

#### text와 password
- **text**: 한 줄짜리 텍스트 입력 (아이디, 이름, 주소 등)
- **password**: 입력 내용이 * 나 • 로 표시됨
~~~html
<form>
  <fieldset>
    <label>아이디: <input type="text" id="user_id" size="10"></label>
    <label>비밀번호: <input type="password" id="user_pw" size="10"></label>
    <input type="submit" value="로그인">
  </fieldset>
</form>
~~~

#### 텍스트·비밀번호 필드 속성
| 속성 | 설명 |
| --- | --- |
| size | 화면에 보이는 글자 수(필드 길이). 최대 10자인데 size가 5면 5자만 보임 |
| value | 필드에 미리 보여 줄 내용. ==비밀번호 필드에는 없음== |
| maxlength | 입력할 수 있는 최대 문자 수 |
- size는 '보이는 길이', maxlength는 '입력 가능한 길이'로 구분

#### search, url, email, tel
- **search**: 검색 필드. x 표시로 검색어를 쉽게 지움
- **url**: 웹 주소 필드 (http:// 로 시작하는 주소)
- **email**: 메일 주소 필드. ==메일 형식을 자동 체크==
- **tel**: 전화번호 필드. ==입력을 체크하지는 않음==

### 선택 필드

#### radio와 checkbox
- **radio**: 여러 항목 중 **하나만** 선택
- **checkbox**: 여러 항목 중 **둘 이상** 선택
~~~html
<label><input type="checkbox" name="prod" value="s_3">선물용 3kg</label>
<label><input type="checkbox" name="prod" value="s_5">선물용 5kg</label>

<label><input type="radio" name="gift" value="yes">선물 포장</label>
<label><input type="radio" name="gift" value="no">선물 포장 안 함</label>
~~~

#### name, value, checked 속성
| 속성 | 설명 |
| --- | --- |
| name | 서버가 버튼을 구분하는 그룹 이름. ==라디오 버튼은 같은 그룹끼리 name을 똑같이== 해야 하나만 선택됨 |
| value | 선택한 항목을 서버에 알려 줄 값. 영문이나 숫자, ==필수 속성== |
| checked | 처음부터 선택된 상태로 표시할 항목 |

### 숫자 입력 필드

#### number와 range
- **number**: 숫자 입력. 브라우저에 따라 스핀 박스로 표시
- **range**: 슬라이드 막대로 숫자 입력
~~~html
<input type="number" min="0" max="5">
<input type="range" min="0" max="100" step="1" value="20">
~~~

#### min, max, step, value
| 속성 | 설명 |
| --- | --- |
| min | 최솟값 (기본 0) |
| max | 최댓값 (기본 100) |
| step | 숫자 간격 (기본 1) |
| value | 초깃값 |

### 날짜와 시간 입력

#### date, month, week
- 달력에서 선택해 입력
- **date**: "yyyy-mm-dd" 형식 (연, 월, 일)
- **month**: "yyyy-mm" 형식 (연, 월)
- **week**: 1월 첫째 주 기준 몇 번째 주인지 표시

#### time, datetime-local
- **time**: 시간 입력. 브라우저마다 모양은 달라도 '오전/오후', '시', '분' 3개 항목으로 구성
- **datetime / datetime-local**: 사용자 지역에 맞는 날짜와 시간을 함께 입력
- (보충) 현재 브라우저는 datetime을 지원하지 않고 datetime-local만 지원

### 버튼

#### submit과 reset
- **submit**: 입력 내용을 서버로 전송
- **reset**: 입력 내용 전부 삭제
- **value**로 버튼에 표시할 글자 지정
~~~html
<form action="return.php" method="POST">
  <input type="submit" value="반품 신청">
  <input type="reset" value="취소하기">
</form>
~~~

#### image
- submit 버튼 대신 이미지를 넣음 (누르면 전송)
- 기본형: input type="image" src="이미지 경로" alt="대체 텍스트"

#### button
- 기능 없이 버튼 모양만 넣음 → 주로 **자바스크립트 실행**에 사용
~~~html
<input type="button" value="공지 창 열기" onclick="window.open('notice.html')">
~~~
- onclick의 window.open은 브라우저에서 새 창을 엶

### 그 밖의 input

#### file
- 파일 첨부. '파일 선택'이나 '찾아보기' 버튼으로 표시됨
- 기본형: input type="file"

#### hidden
- 사용자에게 보이지 않는 숨겨진 필드. 폼을 전송할 때 서버로 함께 전송됨
- 렌더링된 페이지에서 볼 방법이 없음
- ==사용자가 바꾸면 안 되는 데이터==를 함께 보낼 때 유용 (갱신할 DB 레코드, 보안 토큰 등)
- 기본형: input type="hidden" name="이름" value="서버로 넘길 값"

## 참고: 컨테이너와 div, span

### 컨테이너

#### 개념
- 콘텐츠나 레이아웃에 아무 영향도 주지 않고, ==여러 요소를 하나로 묶어 관리하기 편하게== 하는 태그
- 콘텐츠를 구분하거나 영역마다 공통 스타일(CSS)을 적용할 때 사용 (예: notice.html의 div id="container")

### 시맨틱과 논시맨틱

#### 시맨틱 태그
- 브라우저, 개발자, 사용자에게 태그 안의 내용을 직접 알려 주는 태그
- header, nav, section, article, aside, footer

#### 논시맨틱 태그
- 아무 의미가 없는 태그. 스타일을 주거나 서버 데이터를 받아 그룹으로 다룰 때 사용
- div, span

### div와 span 비교

#### div
- **박스 형태**로 영역이 잡힘 (블록)
- width, height 지정 가능
- ==자동으로 줄 바꿈==
- margin이 4방향 모두 적용되고, 위아래로 겹치는 여백은 더해지지 않고 겹쳐짐(상쇄)

#### span
- **줄 단위**로 영역이 잡힘 (inline)
- ==width, height 지정 불가==
- 줄 바꿈 없이 옆으로 나열
- margin은 양옆으로만 적용되고 겹쳐지지 않음

# 시험 대비 체크

## 헷갈리기 쉬운 짝
- head(화면에 안 보이는 문서 정보) vs header(body 안의 화면 헤더 영역)
- section(의미 있는 콘텐츠 묶음) vs div(스타일용 묶음)
- strong/em(의미 강조) vs b/i(모양만)
- object의 파일 속성은 data, embed·audio·video·img는 src
- rowspan(세로로 합침) vs colspan(가로로 합침)
- size(보이는 길이) vs maxlength(입력 가능한 길이)
- id(고유 식별) vs class(재사용) vs name(서버 전송)
- get(주소에 노출, 길이 제한) vs post(노출 안 됨, 제한 없음)
- radio(하나만, 같은 name) vs checkbox(여러 개)
- email(형식 체크함) vs tel(체크 안 함)

## 닫는 태그가 없는 태그
- br, hr, img, input, embed, meta (보충: meta 포함)

## 자주 나올 만한 규칙
- img의 width/height는 하나만 지정해도 비율 유지
- autoplay는 muted와 함께 써야 자동 재생됨
- main은 문서에 한 번만, id는 문서에서 중복 불가
- 비밀번호 필드에는 value 속성이 없음
- label의 for와 input의 id 값이 같아야 연결됨
- HTML5에서 p 태그의 align 속성은 지원하지 않음
