## Step 3. 텐서 생성

- 텐서 속성: x.dtype(정수 → int64, 실수 → float32), x.dim(), x.shape(= x.size()), x.numel(), x.item(), x.numpy()
- torch.tensor(data, dtype=): 데이터를 복사해서 텐서 생성 (torch.from_numpy는 메모리 공유)
- id(x): x = torch.tensor(...)는 새 객체라 id가 바뀌고, x.data = ...는 같은 객체의 데이터만 교체해서 id 유지
- x.stride(): 다음 원소로 가기 위해 건너뛰는 메모리 칸 수 (2×3 텐서는 (3, 1))
- 채우기: zeros, ones, full, empty(초기화 안 함), 끝에 _like가 붙으면 입력과 같은 모양·자료형
- 범위: arange(start, end, step)은 end 제외, linspace(start, end, steps)는 끝값 포함
- 난수: rand([0, 1) 균등분포), randn(평균 0, 표준편차 1), randint, randperm, normal, manual_seed로 재현
- 복사: clone(새 메모리), detach(기록 끊기), copy_ / 끝에 _가 붙으면 제자리 연산
- 장치: x.to(device), x.cuda(), x.cpu(), x.is_cuda (모델과 데이터는 같은 장치에)

- torch.index_select(x, dim, index): dim 방향으로 index 위치만 선택

## Step 7. 텐서 함수 기초

- min, max: dim을 주면 (값, 인덱스)를 둘 다 반환, keepdim=True면 줄어든 차원을 크기 1로 유지

## Step 8. 행렬 연산 (선형대수)

- matmul / @: 1차원끼리는 내적, 벡터와 행렬은 벡터 위치에 따라 결과가 다름
- mm은 2차원 행렬곱, bmm은 (b, n, m) @ (b, m, p) → (b, n, p)
- torch.allclose(a, b): 오차 범위 안에서 같은지
- LA.norm(프로베니우스 노름), A.T(전치), LA.det(행렬식), LA.matrix_rank, LA.inv, torch.eye(n)(단위행렬), torch.dist(두 텐서의 거리)
- 연립방정식 Ax = b
    - LA.solve(A, b)가 inv(A) @ b보다 빠르고 정확

    - LU 분해: lu_factor, lu_solve, lu_unpack (A = P L U)
- 방정식 수 > 미지수 수이면 최소제곱해
    - 정규방정식 (AᵀA)x = Aᵀb
    - 의사역행렬 LA.pinv(A) @ b
    - LA.lstsq(A, b).solution
    - 세 방법의 해는 같음

## Step 9. 자동미분 (autograd)

### 미분을 왜 쓰나

- 미분값(기울기) = x를 조금 움직이면 f가 얼마나, 어느 방향으로 변하는가
- 학습은 손실을 줄이는 방향으로 파라미터를 조금씩 옮기는 것 → 매 반복마다 **현재 위치의 기울기 숫자**가 필요
- 도함수 식(2x 같은 것)은 필요 없고, 지금 x 값에서의 기울기만 있으면 됨

### 수치미분 [0901]

- x를 아주 조금(h) 움직여서 f의 변화량을 잰다
- 전방 차분: (f(x+h) − f(x)) / h
- 중앙 차분: (f(x+h) − f(x−h)) / 2h → 더 정확해서 교재가 사용
- h는 보통 0.001 정도 (너무 크면 근사가 부정확, 너무 작으면 실수 오차)
- 주의할 점
    - 분자는 **빼기**, 분자 전체와 분모 2 * h를 각각 괄호로 묶어야 함
    - 변수가 여러 개면 원소마다 편미분: 그 원소만 ±h로 바꾸고 나머지는 그대로 둔 채 **f 전체**를 다시 계산, 원래 값은 tmp에 저장했다가 되돌림
    - f(x[i] + h)처럼 원소 하나만 넣으면 sum(x²)처럼 변수가 안 섞이는 함수에서만 우연히 맞음
    - grad = torch.zeros_like(x): 결과를 담을 같은 크기의 빈 그릇
    - x.shape는 1차원이어도 torch.Size([3]) 튜플 → range()에는 x.shape[0] (= len(x))
- 한계: 근사값이라 오차가 있고, 변수 하나당 f를 두 번씩 계산해야 해서 변수가 많으면 느림

### 자동미분의 핵심 [0902]

- requires_grad=True: "이 텐서로 하는 계산을 기록해 둬"라는 표시
    - grad에 값을 넣는 게 아님. 이 시점에 x.grad는 None
- 계산 그래프: y = x ** 2를 실행하면 y에는 값(4)이 들어가고, "x를 제곱해서 만들었다"는 기록(grad_fn)이 붙음
    - 식이 저장되는 게 아님
- y.backward(): 기록을 거꾸로 따라가며 기본 연산의 미분 규칙 + 연쇄법칙으로 기울기를 계산해 각 입력의 .grad에 저장
- x.grad: x 객체 안의 별도 칸. x 값(2.0)은 그대로, grad 칸에만 4가 들어감
    - 파라미터마다 자기 기울기를 붙여 두는 규칙 → 옵티마이저가 "값 −= lr × grad"만 반복하면 됨
- 수치미분과의 차이: h가 없어 정확하고, 변수가 아무리 많아도 backward 한 번에 모든 .grad가 채워짐
- leaf와 retain_grad()
    - 직접 만든 x는 leaf → grad 저장됨
    - 중간 결과 y는 기본으로 grad를 버림 → y.retain_grad()를 해야 y.grad가 남음 (x.grad와는 무관한 선택 옵션, y.grad는 dy/dy = 1)
- 기록이 붙은 텐서를 numpy로 바꿀 때는 x.detach().numpy()

### 기울기 누적 [0903]

- backward는 grad를 덮어쓰지 않고 **더함**
- 다음 계산 전에 x.grad.zero_()로 초기화해야 함 (학습 루프의 optimizer.zero_grad()와 같은 역할)

### 여러 변수, sum·mean [0904 ~ 0905]

- z = x² + y² → backward 한 번에 x.grad = 2x, y.grad = 2y
- x.sum()의 미분: 모두 1 / x.mean()의 미분: 모두 1/n
- (x**2).mean() (x = [2, 3, 4])
    - 값: 제곱의 평균 = (4 + 9 + 16) / 3 = 9.6667 (평균의 제곱 9와 다름)
    - x.grad: 원소별 2xᵢ/3 = [1.33, 2, 2.67] **벡터** (미분값의 평균이 아님, 다 더하면 6)
- **는 거듭제곱, *는 곱하기

### 출력이 벡터일 때 [0906 ~ 0908]

- backward()는 기본적으로 출력이 스칼라(값 하나)여야 함
- 벡터 출력은 y.sum().backward() 또는 y.backward(gradient=torch.ones_like(y)) (ones면 sum과 같음)
- retain_graph=True: backward 후 기록이 지워지지 않게 해서 다시 backward 가능
- torch.autograd.grad(outputs, inputs): .grad에 저장하지 않고 기울기를 바로 반환, 벡터 출력이면 grad_outputs 사용

### 그래프와 야코비안 [0909 ~ 0911]

- y = sin(x)를 backward하면 x.grad = cos(x)임을 확인
- 야코비안: 출력 여러 개 × 입력 여러 개의 편미분을 모은 행렬
    - torch.autograd.functional.jacobian(f, inputs)
    - [0911]은 출력 원소마다 backward해서 직접 만드는 방법

## Step 10. 경사하강법 (Gradient Descent)

- 아이디어: 공이 경사를 따라 굴러 내려가듯, 기울기 반대 방향으로 조금씩 이동
- 갱신식: **x ← x − lr × f'(x)**
    - 기울기가 양수 → 왼쪽으로, 음수 → 오른쪽으로 이동
    - 기울기가 0에 가까워지면 거의 안 움직임 → 그 위치가 극소점
- 방정식 f'(x) = 0을 푸는 게 아니라, **반복해서 굴러가다 멈춘 곳**이 답
- 하이퍼파라미터
    - lr(학습률): 한 번에 이동하는 크기. 너무 작으면 느리고, 너무 크면 튀어나가 발산
    - max_iters: 최대 반복 횟수
    - tol: 이동량이 이보다 작으면 수렴으로 보고 종료
- 갱신은 미분 추적 없이: x.data = x.data - step (또는 with torch.no_grad(): 안에서)
- 매 반복마다 x.grad.zero_()로 기울기 초기화
- 시작점이 중요
    - 시작 위치 근처의 골짜기(지역 최솟값)로만 감
    - 3차함수처럼 한쪽이 끝없이 내려가는 함수는 잘못된 쪽에서 시작하면 발산
- 2변수 [1002]: x = [x0, x1] 벡터도 똑같이, torch.dist(x_old, x)로 이동량을 재서 종료 판단
- 그래프: torch.meshgrid로 격자 좌표, ax.contourf(등고선), ax.plot_surface(곡면)

### 극대점 찾기 (과제 1번 관련)

- 옵티마이저는 항상 **내려가는** 방향으로만 이동 → 그대로는 극소만 찾음
- 극대를 찾으려면 **−f(x)를 최소화** (그래프를 뒤집으면 꼭대기가 골짜기가 됨)
- 극대·극소를 둘 다 구하려면 손실만 f, −f로 바꿔 **두 번** 최적화
- 시작점은 변곡점(f''(x) = 0) 기준으로 각각 맞는 쪽에서

## Step 11. torch.optim 최적화

- Step 10에서 직접 하던 갱신을 옵티마이저가 대신
    - optimizer = optim.SGD(params=[x], lr=0.001): 최적화할 텐서 목록과 학습률 전달
    - optimizer.zero_grad(): 모든 파라미터의 grad 초기화
    - loss.backward(): 기울기 계산
    - optimizer.step(): 파라미터 한 번 갱신
- 옵티마이저 종류
    - optim.SGD: 기본 경사하강법 (momentum 옵션으로 이전 이동 방향을 관성처럼 반영)
    - optim.Adagrad: 많이 갱신된 파라미터일수록 학습률을 줄임
    - optim.RMSprop: 최근 기울기 크기의 이동평균으로 학습률 조절
    - optim.Adam: 모멘텀 + RMSprop, 가장 많이 씀 (기본 lr = 0.001)
- optimizer.defaults: 기본 설정값 확인
- 여러 파라미터는 리스트로 한꺼번에 전달: optim.SGD([x, y], lr=0.1)

---

## Step 12. 단순 선형회귀

- 모델: **y = w·x + b** (w: 기울기, b: 절편 → 학습할 파라미터)
- 목표: 데이터(x, t)에 가장 잘 맞는 w, b 찾기
- 손실 함수 MSE(평균제곱오차): mean((y − t)²)
    - 직접 계산: torch.mean((y - t)**2)
    - torch.nn.MSELoss(): 손실 함수 객체 (loss_fn(y, t)로 호출)
    - F.mse_loss(y, t): 함수형 (결과 동일)
- 학습 루프 5단계
    1. 예측 y = x*w + b
    2. 손실 loss = loss_fn(y, t)
    3. optimizer.zero_grad()
    4. loss.backward()
    5. optimizer.step()
- 손실이 줄어드는지 loss_list에 모아 그래프로 확인
- 경사하강법 문제와의 차이: 이번에는 x가 아니라 **w, b가 움직이는 변수**, 손실 함수가 최소화 대상

---

## Step 13. 다변수 선형회귀

- 특징(입력)이 여러 개: t = w1·x1 + w2·x2 + b
- 행렬 형태: **y = X @ W + b**
    - X: (샘플 수, 특징 수) = (8, 2)
    - W: (특징 수, 출력 수) = (2, 1)
    - 결과: (8, 1)
- 데이터 분리
    - train_data[:, :-1]: 마지막 열을 뺀 입력
    - train_data[:, -1:]: 마지막 열만, 2차원 유지 → (8, 1)
- torch.matmul(X, W) = X @ W

---

## Step 14. 다항식 회귀

- 모델: y = b + W[0]·x + W[1]·x² + … + W[n−1]·xⁿ
- 곡선 데이터를 n차 다항식으로 근사, 차수 n을 바꿔가며 비교
    - 차수가 너무 낮으면 데이터 모양을 못 따라감 (과소적합)
    - 너무 높으면 노이즈까지 따라감 (과적합)
- 여전히 파라미터(W, b)에 대해서는 선형이라 같은 학습 루프로 학습
- torch.normal(mean, std, size)로 노이즈를 섞어 데이터 생성

---

## Step 15. 미니 배치 학습

- 전체 데이터를 한 번에 쓰지 않고, 작은 묶음(배치)마다 파라미터를 갱신
    - 메모리 절약, 더 자주 갱신, 무작위성이 지역 최솟값 탈출에 도움
- 용어
    - 배치 크기(batch_size): 한 번에 쓰는 샘플 수
    - K = ceil(데이터 수 / batch_size): 한 epoch의 배치 개수
    - epoch: 전체 데이터를 한 바퀴 다 쓰는 것
- 직접 뽑기 [1501]
    - torch.randint(high=n, size=(batch,)): 복원 추출 (중복 가능)
    - torch.randperm(n)[:batch]: 비복원 추출
- TensorDataset + DataLoader [1502]
    - TensorDataset(x, t): 입력과 정답을 샘플 단위 (x[i], t[i])로 묶음
    - DataLoader(ds, batch_size=4, shuffle=True): 매 epoch 섞어서 배치 단위로 꺼내줌
    - for X, y in data_loader:로 배치 반복
    - len(data_loader): 배치 개수
- epoch 손실은 배치 손실의 평균으로 기록

---

## Step 16. 선형 모델: 1-뉴런 (nn.Linear)

- nn.Linear(in_features, out_features, bias=True): **y = x @ Wᵀ + b**를 계산하는 완전연결 층
    - model.weight: (out, in) 모양, model.bias: (out) 모양
    - 파라미터가 자동으로 생성·초기화되고 requires_grad=True
- model(x): 순전파(forward) 계산
    - 입력은 (샘플 수, 특징 수) 2차원 → 1개 특징이면 x.view(-1, 1)
- nn.Parameter(tensor): 학습 파라미터로 등록되는 텐서
- model.parameters(): 학습 파라미터 목록 → 옵티마이저에 전달
- model.state_dict(): 파라미터 이름 → 값 딕셔너리 ('weight', 'bias')
- 뉴런 1개 = 입력의 가중합 + 편향 → 이게 선형회귀 그 자체

---

## Step 17. nn.Module 상속 클래스

- 신경망 모델은 nn.Module을 상속한 클래스로 만든다
    - __init__: super().__init__() 호출 후 사용할 층을 self.이름으로 등록 → 파라미터가 자동으로 model.parameters()에 포함
    - forward(self, x): 순전파 계산 정의 → model(x)를 호출하면 자동 실행
- 하위 층 접근: model.linear.weight.data
- state_dict 키는 '속성이름.파라미터이름' ('linear.weight', 'linear.bias')
- 장점: 층이 많아지고 계산이 복잡해져도 구조를 깔끔하게 관리

---

## Step 18. 모델 저장 · 로드 · 평가 모드

- 모드 전환
    - model.train(): 학습 모드
    - model.eval(): 평가 모드 (Dropout 끔, BatchNorm은 저장된 통계 사용)
    - 평가할 때는 with torch.no_grad():로 기록도 끔
- 저장 방식
    - torch.save(model, 경로): 구조 + 파라미터 통째로 → 로드 시 torch.load(경로, weights_only=False)
    - torch.save(model.state_dict(), 경로): 파라미터만 (**권장**) → 같은 구조 모델을 만든 뒤 model.load_state_dict(torch.load(경로))
    - 체크포인트: {'epoch', 'model': state_dict, 'optimizer': optimizer.state_dict()}를 딕셔너리로 저장 → 학습을 이어서 할 때
- TorchScript (파이썬 클래스 정의 없이도 로드 가능)
    - torch.jit.trace(model, 예시입력): 입력을 흘려보내며 연산을 기록해 변환
    - torch.jit.script(model): 코드를 분석해 변환 (if/for 같은 제어문 보존)
    - torch.jit.save / torch.jit.load
- ONNX: 다른 프레임워크에서도 쓰는 형식
    - torch.onnx.export(model, 예시입력, 경로), dynamic_axes로 배치 크기 가변
    - onnxruntime.InferenceSession(경로), sess.run(None, {입력이름: 데이터})로 추론

## Step 19. 활성화 함수

- 역할: 층 사이에 비선형성을 넣음
    - 선형 층만 쌓으면 결국 하나의 선형 함수와 같아서 층을 쌓는 의미가 없음
- 종류
    - nn.Sigmoid: 1 / (1 + e⁻ˣ), 출력 (0, 1) → 이진 분류 확률. 미분 최댓값이 0.25라 깊어지면 기울기가 작아짐(기울기 소실)
    - torch.logit: 시그모이드의 역함수
    - nn.LogSigmoid: log(sigmoid(x))
    - nn.Tanh: 출력 (−1, 1), 0 중심 대칭
    - nn.ReLU: max(0, x), 계산이 빠르고 기울기 소실이 적어 은닉층에 가장 많이 씀
    - nn.LeakyReLU: 음수 구간에 작은 기울기(0.01)를 줘서 0이 되지 않게
    - nn.Softmax(dim=1): 합이 1인 확률 분포로 변환 → 다중 분류
    - nn.LogSoftmax(dim=1): log(softmax), NLLLoss와 함께 사용
- 예측 클래스는 torch.argmax(출력, dim=1)

## Step 20. 손실 함수

### 회귀
- nn.MSELoss: 평균제곱오차

### NLL [2001]

- 정답 클래스의 확률 p가 1에 가까울수록 −log(p)는 0에 가까워짐
- nn.NLLLoss / F.nll_loss: 입력은 **log 확률**(LogSoftmax 출력), 정답은 클래스 번호(int64)
- reduction: 'none'(샘플별), 'sum'(합), 'mean'(평균, 기본값)
- weight: 클래스별 가중치 (불균형 데이터에 사용)

### 이진 분류 BCE [2002]

- 식: −(t·log(y) + (1−t)·log(1−y))
- nn.BCELoss: 입력은 **sigmoid를 거친 확률**, 정답은 0/1 실수형
- nn.BCEWithLogitsLoss: sigmoid + BCE를 한 번에, 입력은 sigmoid 전 점수(logit) → 수치적으로 안정적, 권장

### 다중 분류 CE [2003]

- nn.CrossEntropyLoss / F.cross_entropy = LogSoftmax + NLLLoss
    - 입력은 **softmax 전 점수(logit)** 그대로 → 모델 마지막에 Softmax를 넣지 않음
    - 정답은 클래스 번호, 또는 원-핫(확률) 텐서도 가능 [2006]

### 세그멘테이션 [2004]

- 픽셀마다 클래스 분류 → 입력 (N, C, H, W), 정답 (N, H, W)
- 클래스 차원이 1번이어야 해서 permute로 순서 변경

### 원-핫 인코딩 [2005]

- F.one_hot(t, num_classes): 클래스 번호 → 원-핫 벡터
- x.scatter_(dim, index, src)로 직접 만들 수도 있음
- 원-핫 → 클래스 번호: argmax(dim=1)

### 정리: 출력층 + 손실 함수 짝

|문제|출력층|손실 함수|
|---|---|---|
|회귀|그대로|MSELoss|
|이진 분류|그대로 (logit)|BCEWithLogitsLoss|
|이진 분류|Sigmoid|BCELoss|
|다중 분류|그대로 (logit)|CrossEntropyLoss|
|다중 분류|LogSoftmax|NLLLoss|

## Step 21. 완전 연결 다층 신경망 (MLP)

- 구조: 입력층 → 은닉층(Linear + 활성화) × n → 출력층(Linear)
- nn.Sequential(층, 활성화, 층, ...): 층을 순서대로 묶은 모듈
- nn.Sequential(*layers): 리스트에 담은 층들을 풀어서 연결 → 은닉층 개수를 리스트로 받는 MLP [2104]
- XOR 문제 [2101]
    - 직선 하나로 나눌 수 없음 → 은닉층이 있어야 풀 수 있음 (MLP가 필요한 이유)
    - AND, OR은 은닉층 없이도 가능
- torchinfo.summary(model, input_size): 층별 출력 모양과 파라미터 수 표
- 평가
    - pred = out.argmax(dim=1): 점수가 가장 큰 클래스
    - 정확도 = (pred == y).float().mean()
    - 학습 데이터 정확도와 테스트 데이터 정확도를 따로 확인 (테스트가 훨씬 낮으면 과적합)
- 결정 경계: 격자 위의 모든 점을 분류해서 plt.contourf(영역), plt.contour(경계선)로 표시
- 실제 데이터 [2102 ~ 2104]
    - np.loadtxt(converters=...)로 CSV의 문자열(품종 이름, x/o/b)을 숫자로 변환
    - 학습/테스트 분할: 섞은 뒤 80% / 20%
    - 입력은 float, 정답 클래스 번호는 long(int64)
    - model.to(DEVICE), 데이터도 같은 장치로
- 하이퍼파라미터: 은닉층 개수·크기, 활성화 함수, lr, batch_size, epoch → 바꿔가며 비교 (과제 2번)
- MLP 구조 용어
    - n_hidden는 은닉층의 뉴런 수(폭, width)이고, nn.Linear의 개수가 층 수(깊이, depth)
    - 4층 MLP는 Linear 4개 + 은닉층 뒤 Sigmoid 3개, 출력층 뒤에는 활성화를 넣지 않음
    - 파라미터 수: 9 → 10 → 2 모델은 (9×10+10) + (10×2+2) = 122개
- 틱택토 예제: 입력 9칸(x = -1, o = 1, b = 0), 출력 2클래스(x 승 / 그 외), 958개를 766 / 192로 분할, CrossEntropyLoss

## 자주 헷갈린 것 모음

- x.shape는 튜플(torch.Size), x.shape[0]은 정수, x.size()와 x.shape는 같음
- 이름 끝 _ (add_, zero_, fill_)는 텐서 자체를 바꾸는 제자리 연산
- requires_grad는 기록 시작, backward는 기록을 보고 .grad에 저장, backward는 grad를 누적하므로 매번 zero_grad()
- optimizer는 이미 계산된 .grad를 읽어 값을 갱신할 뿐, 기울기는 backward가 구함
- 확률과 정확도는 다름: 확률은 모델 출력, 정확도는 정답과 비교한 맞힌 비율
- argsort는 값이 아니라 정렬했을 때 각 자리에 올 원래 인덱스를 반환
- view는 연속 텐서에서만 가능하고 메모리 공유, reshape는 필요하면 복사
