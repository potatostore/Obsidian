# IP·판권

## 대상 IP: 게임 속 바바리안으로 살아남기 (2026-10-15 기준)
- 작가 정윤강, 출판사 제이플미디어
- 네이버 시리즈 연재, 2021-03-31 시작. 2026-06-10, 944화 시점에 '작품 재정비'로 무기한 휴재
- 네이버 시리즈 조회수 약 1억 394만, 별점 9.1 (나무위키, 2025-10 기준)
- 웹툰: 네이버웹툰 연재. 씨엔씨레볼루션 IP 목록에 MIDNIGHT STUDIO, 팀 더 지크, 정윤강 크레딧
- 공식 게임화 발표: 찾지 못함. 발표가 없다고 계약이 없는 건 아님
- 선례: 2026년 4월 itch.io에 공개된 팬게임(Godot, 사이드뷰 액션 로그라이크)이 원작사 요청으로 7월 15일 종료 예정이었음 (나무위키, 단일 출처)

## 권리 구조 메모
- 소설: 작가 + 제이플미디어. 게임화 권리를 누가 쥐는지는 문의로 확인
- 웹툰: 웹툰 그림은 웹툰 제작진의 별도 저작물 → 웹툰 디자인을 쓰려면 따로 허락 필요
- 게임 캐릭터 디자인은 기본적으로 직접 하고, 웹툰 디자인 활용은 협상 항목으로 남김

## 전략
1. 시스템·엔진은 IP 없이 개발 ([[03 게임 개요]]의 3층 구조)
2. 겜바바 스토리·규칙 분석은 이 Obsidian 안에서만 (비공개 기획 문서)
3. 기반 시스템이 완성되고 겜바바 색을 입히려는 시점에 판권 문의
4. 그 사이 게임화 판권이 다른 곳에 팔리면, 시스템은 그대로 두고 다른 후보 IP로 전환 ([[01 회사·사업]])

## 공개 원칙
- 공개물(영상, SNS, 블로그, 공모전, 스토어 페이지)에는 겜바바의 이름·지명·캐릭터·정수 이름을 쓰지 않는다
- 공개용 데모는 오리지널 팩으로만. 오리지널 팩의 이름과 세부 규칙은 겜바바와 겹치지 않게 다듬는다
- 게임 규칙 자체는 보통 저작권 보호 대상이 아니라고 보지만, 겜바바 규칙 조합이 그대로 드러나면 무단 각색으로 비칠 수 있다. 정확한 선은 계약 전에 법률 자문으로 확인

## 판권 문의 때 준비할 것
- [ ] 1~2분 플레이 영상 + 플레이 가능한 빌드
- [ ] 원작 이해도를 보여주는 기획서 (스토리 매핑, 정수 시스템 구현 방식)
- [ ] 조건 초안: 계약금, 러닝 로열티, 독점 범위, 기간, 플랫폼(PC/Steam), 지역, 원작 변경 시 대응
- [ ] 제이플미디어의 2차 창작·공모전 정책 원문 확인 (메인 페이지에 2차 창작 환영·공모전 안내가 있다고 함)
- [ ] 법률 자문 (AI 생성 에셋의 권리 문제 포함)
