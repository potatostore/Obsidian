# 세계·미궁·스토리

## 미궁 원작 규칙 (나무위키 요약, 원작 확인 필요)
- 월 1회 차원광장에서 포탈이 열리고, 입장 위치는 무작위
- 층별 폐쇄 시점: 1층 168시간, 2층 240시간, 3층 15일, 4층 23일, 5층 30일, 6층 60일, 7층 75일
- 층이 닫히면 그 층의 탐험가는 다음 날 정오에 도시로 강제 귀환. 조기 탈출 수단 없음
- 1~5층은 매달 초기화, 6층부터는 시간이 이어지고 흔적이 남음
- 아이템이 아닌 부산물(시신 포함)은 특수 마법 없이는 가지고 나올 수 없음
- 층 사이에는 포탈 비석이 있고, 아래층으로 가려면 그 층에서 포탈을 열어야 함
- 차원 붕괴: 예고 없이 탐험가와 몬스터가 무작위 위치로 전이되는 사건. 운이 좋으면 균열·히든 필드 진입

| 층 | 원작 구조 | 게임 구조 아이디어 |
| --- | --- | --- |
| 1층 수정동굴 | 동굴, 2층으로 가는 포탈 4개 | 튜토리얼 원정 |
| 2층 | 짐승의 소굴·망자의 땅·바위사막·고블린 숲 등 4개 필드 | 필드 선택 분기 |
| 3층 순례자의 길 | 10개 이상 필드가 이어진 넓은 층 | 긴 원정, 보급 관리 |
| 4층 천공의 탑 | 독립 계층, 스테이지형 시련 (100스테이지 이후 5층 포탈 탐색) | 연속 전투 챌린지 |
| 5층 대마경 | 복잡한 오픈 월드, 클랜 규모 사냥 | 부대 전투 도입 |
| 6층 대해 | 배로 섬을 거치며 항해 | 항해·거점 |
| 7층 | 암흑대륙으로 가는 길목 | 후반 |
| 부가 구역 | 지하 1층, 균열, 히든 필드 | 특수 원정 |

## 원정 구조 (시스템 층)
- 원정 = 층 하나를 체류 기간 동안 탐험하는 단위
- 층 지도는 노드형(전투·이벤트·채집·휴식), 이동할 때마다 시간 소모
- 층이 닫힐 때까지 버텨야 함 → 보급, 부상, 기력이 원정 내내 이어지는 자원
- 1~5층은 매달 초기화 → 반복 원정 / 6층부터는 상태 유지 → 장기 원정
- 차원 붕괴 → 원정 중 무작위 이벤트

## 마을
- 원작 조직: 탐험가 길드, 마탑, 클랜, 귀족, 신전(삼신교), 환전소
- 이전 초안 시설: 상점, 대장간, 수리점, 경매장, 선술집, 도서관
- 기능 매핑(안): 길드(의뢰·등급 심사), 신전(정수 제거), 환전소(마석 → 스톤), 대장간·수리점(장비), 경매장(정수·넘버즈 거래), 클랜 하우스(동료 관리), 도서관(도감·정수 정보)
