# 성장·아이템

원작 규칙을 기준으로 정리하고, 시스템 층에서 쓸 일반화된 이름을 붙인다. 원작 규칙은 나무위키 요약이라 원작으로 다시 확인한다.

## 결정
- 성장 규칙은 원작 기준. 게임 템포가 너무 느려지면 그때 보정 (미니게임 등은 보정 수단 후보로 보류)
- 동료도 정수를 흡수한다
- 동료 정수는 플레이어가 자유롭게 고른다. 단, 스토리에 필요한 정수는 스토리 진행으로 자연스럽게, 반드시 획득한다
	- 정해야 할 예외: 정수 칸이 가득 찼을 때, 이미 가진 정수와 스킬이 겹칠 때(원작은 중복 흡수 불가), 플레이어가 그 정수를 제거하려 할 때
	- 후보: 스토리 정수는 별도 고정 칸에 들어감 / 획득 직전에 칸을 비우도록 안내 / 스토리 정수는 제거 불가로 표시

## 원작 규칙 요약 (겜바바 팩)

### 레벨
- 레벨업하면 영혼력(MP) 증가: 1~5레벨은 레벨당 +10, 6레벨부터 +30
- 레벨 1당 흡수할 수 있는 정수 칸 +1
- 경험치는 몬스터 종류별 첫 처치 때만 지급. 포탈 첫 개방 같은 일부 경험치는 영구 누적
- 정수를 흡수하지 않으면 다음 경험치를 얻기 어려움 → 정수가 성장의 병목
- 이벤트로 레벨이 떨어지면 그만큼 정수 칸이 무작위로 잠김

### 스탯
- 메인 스탯 3종: 육체, 정신, 이능. 각각 아래에 세부 스탯이 많음
- 세부 스탯마다 계수(0.5~3)가 있어서 메인 스탯에 반영되는 정도가 다름
- 캐릭터 생성 때 기본 수치는 정해진 범위 안에서 무작위
- 희귀 스탯은 특정 몬스터에게서만 얻음
- 기력이 일정 이하면 행동 불가. 저주가 15중첩 이상이면 치료 전까지 신체 능력이 영구 하락

### 정수
- 획득: 몬스터 처치 시 드롭. 일반 0.01%, 등급이 높을수록 약간 높음. 균열의 수호자 정수는 33%
- 흡수: 몸에 대면 흡수. 일반 정수는 그 몬스터의 액티브 1개 + 패시브 1개 + 기본 스탯
- 색: 어떤 액티브를 얻는지 결정. 수호자 정수는 무지개색이고 액티브 전부 + 스탯 1.5배
- 등급: 1~9등급, 숫자가 작을수록 높음
- 종류: 일반, 수호자, 계층(캐릭터당 1개), 변종(지하 전용), 맞춤형(마석 조합)
- 중복 불가: 스킬이 하나라도 겹치면 흡수되지 않음
- 업그레이드: 같은 계열 일반 정수를 가진 상태에서 수호자 정수를 흡수하면 수호자로 바뀜
- 제거: 신전에서만 가능. 첫 비용 500만 스톤, 이후 2배씩 증가. 계층 정수는 제거 불가
- 분배: 파티에서 흡수할 사람을 정하고, 흡수자가 시세 기준으로 나머지에게 돈을 줌. 경쟁하면 경매. 30분 안에 아무도 안 쓰면 소멸
- 정수로 얻은 스킬은 원래 몬스터가 쓰는 것보다 대개 약함

### 넘버즈
- 균열 수호자 등에게서 얻는 고유 능력 장비. 정수보다 우선순위는 낮지만 성장 한계에서 쓰는 스펙업 수단
- 번호 체계와 전체 목록: [[03-2a 넘버즈 목록]]

### 경제
- 화폐: 스톤. 기초 재화는 마석(몬스터 사냥) → 환전소에서 탐험가 등급에 따라 스톤으로 바꿈
- 탐험가 등급: 몸에 새겨진 정수의 총량으로 결정

## 시스템 층 일반화
오리지널 팩 이름은 전부 가칭.

| 원작 용어 | 시스템 개념 | 오리지널 팩 가칭 |
| --- | --- | --- |
| 정수 | 몬스터에게서 얻는 능력 슬롯 아이템 (스탯 + 패시브 + 액티브) | 코어 |
| 정수 색 | 액티브 스킬을 고르는 분류 키 | 계열 |
| 수호자 정수 | 상위판 (액티브 전부 + 스탯 배율) | 왕관 코어 |
| 영혼력 | 액티브 스킬 자원 | 마나 |
| 레벨 = 정수 칸 | 레벨만큼 슬롯 | 그대로 |
| 종별 첫 처치 경험치 | 도감 등록 경험치 | 그대로 |
| 넘버즈 | 세계에 하나뿐인 번호 아이템 | 유물 |
| 스톤 / 마석 | 화폐 / 기초 재화 | 미정 |
| 탐험가 등급 | 슬롯 아이템 총량 기반 등급 | 미정 |

## 게임으로 옮길 때 정할 것
- [ ] 드롭률: 원작 0.01%는 게임 템포에 안 맞음 → 보스 확정 드롭, 정수 사냥 의뢰 등으로 '희귀하지만 계획할 수 있게'
- [ ] 세부 스탯을 얼마나 보여줄지 (전부 / 핵심 몇 개 / 숨김)
- [x] 동료도 정수 흡수 → 수십 명의 정수를 다룰 도구 필요 (흡수자 추천, 비교 화면, 필터)
- [x] 스토리 동료·주인공의 정수 → 자유 선택 + 스토리 필수 정수는 반드시 획득 (위 '결정' 참고)
- [ ] 정수 분배·경매를 동료 관계 시스템으로 살릴지
- [ ] 제거 비용 2배 증가를 그대로 둘지 (빌드 실험을 얼마나 막을지)
- [x] 넘버즈 원작 목록 정리 → [[03-2a 넘버즈 목록]] (게임용 변환은 그 문서에서)

## 이전 초안에서 가져올 것
- 장비 등급(노멀·에픽·유니크·레전더리·시크릿), 무게(속도 감소), 내구도(성능 × 내구도)
- 초안의 시크릿 장비 → 원작의 시크릿 넘버즈로 통합 검토 ([[03-2a 넘버즈 목록]])
- 초안의 아카데미 훈련·스탯 미니게임은 원작 성장 구조와 충돌 → 보류
