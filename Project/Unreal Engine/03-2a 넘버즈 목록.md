# 넘버즈 목록

원작의 넘버즈(넘버스) 아이템을 게임 데이터로 옮기기 위한 카탈로그. 나무위키 '설정' 문서 5.3을 요약했고, 효과는 짧게 줄였다. 원작으로 다시 확인한다.

## 공통 규칙
- 주 획득처는 균열의 수호자. 균열 보상은 정수 또는 넘버즈 33%, 균열석 66% (원작 190화)
- 그 밖의 획득처: 피오네 섬, 4층 시련 보상 상자(132화), 오크 히어로·반데몬 같은 특수 몬스터
- 하나하나가 고유 능력을 가진 장비. 제작·발견을 빼면 사실상 유일한 장비 수급처
- 정수보다 우선순위는 낮지만, 성장이 한계에 닿았을 때 가장 쉬운 스펙업 수단
- 번호는 한 감정사가 보구 1만 개를 책 한 권으로 정리하면서 생김. 대체로 번호가 낮을수록 귀하지만, 번호와 무관하게 대부분 비쌈
- 일부는 도시에서 사용 불가, 일부는 비전투 중에만 사용 가능
- 상위 개념으로 계층보구가 있음

## 게임 시스템으로 옮길 때
- 유일 아이템 관리: 번호마다 세계에 하나 → 소유 상태(미발견·플레이어·NPC·경매장)를 추적하는 레지스트리
- 획득 경로 데이터: 균열의 층 제한(3층 미만 전용, 5층 전용 등), 특정 보스, 스토리 이벤트, 경매장
- 효과 유형이 다양함 → 범용 효과 시스템 필요 ([[05 언리얼 기술]]의 GAS 검토와 연결)
	- 상시 능력치 (피해 감소, 내성)
	- 조건 발동 (치명상, 공간 이동 마법 감지)
	- 사용 효과 + 쿨타임 / 사용 횟수 / 소모형
	- 세트 효과 (시체술사의 기만 + 오만)
	- 사용 제한 (도시 불가, 비전투 전용)과 패널티 (민첩 −80%)
	- 탐색·이벤트 보조 (운명 추적자, 반딧불 반지, 어긋난 신뢰) → 원정 이벤트 시스템과 연결
	- 뽑기형 (가르파스의 목걸이, 마카이로의 보관함)
	- 소환형 (한스 페럿의 나들이 인형: 소환물도 정수 시스템을 씀)
- 시간 단위 변환표 필요: 원작의 초·분·시간 → 전투 턴(CT)·원정 일수 (예: '3초간' → 1턴, '쿨타임 하루' → 원정 하루)
- 장비 부위 목록 필요: 무기, 방패, 갑옷(내갑), 부츠, 벨트, 반지, 목걸이, 팔찌, 귀걸이, 머리 + 부적 1칸
- 넘버즈마다 등장 페이즈 표시 → 1페이즈에 나오는 것부터 구현
- 목록에서 드러난 원작 시스템도 함께 필요
	- 결속(파티 연결) 상태: 신뢰, 아이기스의 장벽, 초심자의 행운 등이 전제로 씀
	- 위협 수치(어그로): 적 AI의 공격 대상 선택 규칙으로 → [[03-1 전투]]
	- 파괴불가 등급(하급·최상급): 이전 초안의 내구도 시스템과 연결
	- 종합 아이템 레벨: 장비 점수 개념
