# 전투

## 방향
- 그리드 전술(트라이앵글 스트래티지식) + 속도 기반 턴 순서
- 동료가 늘어나는 후반에는 부대 단위 지휘 + 자동 전투(유니콘 오버로드식)로 피로도 관리

## 턴 순서: 속도 기반 CT
- 이전 초안의 "속도 100과 94는 100:94 비율로 행동"을 그대로 구현하는 방식
- 유닛마다 시간 단위로 속도만큼 게이지(CT)를 쌓고, 100이 되면 행동 (파이널 판타지 택틱스 방식)
- 다음 몇 턴의 행동 순서를 타임라인으로 보여줘서 플레이어가 미리 계획

## 규모 단계
| 단계 | 원작 규모 | 전투 방식 | 출전 인원(안) |
| --- | --- | --- | --- |
| 초반 | 소규모 파티 | 개별 유닛 그리드 전투 | 4~5 |
| 중반 | 팀(10명 안팎) | 개별 유닛 그리드 전투 | 8~10 |
| 후반 | 클랜(수십 명) | 부대 단위 지휘 + 부대 안은 자동 전투 | 부대 3~5개 |

- 전체 동료 수는 늘어나도 한 전투의 출전 인원에는 상한을 둔다
- 출전하지 않은 동료의 쓰임: 파견 의뢰, 정수 사냥, 제작 등 (미정)
- 원작 근거: 4등급 이상 팀은 대부분 클랜 단위로 활동, 5층 대마경은 클랜 규모 사냥에 맞는 구조 ([[03-3 세계·미궁·스토리]])

## 자동 전투: 작전 규칙
- 유닛마다 '조건 → 행동' 목록을 설정 (예: 아군 체력 30% 이하 → 회복 / 가장 가까운 적 → 공격)
- 하나의 시스템을 두 곳에 쓴다: 그리드 전투의 자동 진행, 후반 부대 전투의 자동 해결
- 처음에는 단순하게 시작하고, 규칙 종류는 점진적으로 늘린다

- [ ] 방향 (측면·후방 공격 보너스)
- [ ] 협공 (아군 사이에 낀 적에게 추가 공격)
- [ ] 지형 효과: 원작 필드 효과(치유 불가, 시야 10m, 소모값 증가 등)를 지형 규칙으로
- [x] 카메라: 고정 구도, 회전 없음 → 아래 '카메라'
- [x] 고정 카메라 각도: 정면(옥토패스식)
- [ ] 전투 때 내려다보는 각도를 탐험 때보다 높일지 (그리드 가독성)
- [ ] 정수 액티브 스킬과 영혼력(MP) 소모 규칙 ([[03-2 성장·아이템]])
- [ ] 쓰러졌을 때: 영구 사망 / 부상 / 귀환 후 회복

## 카메라 (고정 구도)
- 회전 없음. 확대·축소 2~3단계 정도만 검토
- 각도 후보

| 후보 | 느낌 | 그릴 스프라이트 방향 (4방향을 바라보는 기준) |
| --- | --- | --- |
| 정면(축 정렬) | 옥토패스 트래블러 같은 정면 디오라마 | 앞·뒤·옆 3종 (옆은 좌우 반전) |
| 대각선(쿼터뷰) | 파이널 판타지 택틱스 같은 쿼터뷰 | 앞대각·뒤대각 2종 (좌우 반전) |

- 고정 카메라의 대가는 '가림': 높은 지형이나 건물 뒤의 유닛·타일이 안 보임
	- 레벨 디자인: 높은 구조물은 맵 뒤쪽이나 가장자리에
	- 가리는 오브젝트 반투명 처리 (디더링 머티리얼)
	- 가려진 유닛 실루엣 표시 (커스텀 뎁스 + 포스트 프로세스) → [[06 아트·머티리얼]]
- 결정: 옥토패스 트래블러식 정면 구도. 스프라이트는 앞·뒤·옆 3종
- 남은 과제: 정면 구도는 뒤쪽 타일이 납작하게 보여 그리드 읽기가 어려움 → 탐험은 낮은 각도, 전투는 조금 더 내려다보는 각도로 전환하는 안을 룩 테스트로 확인

## 데미지 공식 (이전 초안 검토)
초안:
- 물리: (공격력 − 방어력) × (1 + (자신 레벨 − 상대 레벨) / 100)
- 마법: (소모한 마나 − 방어력) × (1 + (자신 레벨 − 상대 레벨) / 100)

검토:
- 초안 설정은 "레벨이 존재하지 않는다"인데 공식에 레벨이 들어 있음 → 원작처럼 레벨을 두면 해결
- 뺄셈 공식은 방어력이 공격력 이상이면 0 또는 음수 → 최소 데미지를 두거나, 비율 공식(예: 공격력 × 100 ÷ (100 + 방어력))으로 바꾸는 선택지
- 원작 스탯은 육체·정신·이능 + 세부 스탯 구조라, 공식은 스탯 구조가 정해진 뒤 확정
