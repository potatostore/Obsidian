# 회사·사업

## 회사 컨셉
웹소설 IP를 가져와 양산형이 아닌, 게임성으로 승부하는 스팀 게임을 만드는 스튜디오. 첫 장르는 HD-2D 전술 RPG.

- 웹소설·웹툰 원작 게임은 많지만 게임성으로 호평받은 사례는 드물다
- 원작 팬덤이 초기 유입을 만든다
- 초대형 IP는 대형사가 가져간다. 예: 『나 혼자만 레벨업』 → 넷마블 『나 혼자만 레벨업: 어라이즈』
- 그래서 대형사가 손대지 않는 중간층 IP를 노린다

## 타깃 IP 선정 기준 (2025 계획서 수정안)
1. 필력보다 스토리가 촘촘하고 탄탄할 것 (기존 유지)
2. 우리 장르에 맞는 구조: 파티·클랜·던전·성장 시스템이 이야기의 중심 (기존 '장르 전문성' → '장르 적합성')
3. 팬덤이 유입될 만큼 인기는 있지만, 대형사가 게임화할 정도는 아닌 중간층 (기존 3번에 상한 추가)
4. 게임화 판권이 비어 있을 것 (문의로 확인)
5. 권리 보유사가 2차 창작에 우호적일 것 (공모전, 가이드라인 등)

## 수익 구조
- Steam 패키지 판매, 게임 내 추가 BM 없음 (2025 계획서의 '플레이타임 50시간 이내'는 폐기)
- 싱글 게임이 됐으므로 상시 게임 서버가 필요 없음 → 계획서의 AWS EC2·RDS 항목은 빼거나 크게 줄임

| 항목 | 조건 |
| --- | --- |
| Steam 수수료 | 매출 1,000만 달러까지 30%, 1,000만~5,000만 달러 25%, 5,000만 달러 초과분 20% |
| Steam Direct 등록비 | 앱당 100달러 (매출 1,000달러를 넘기면 돌려받음) |
| 언리얼 로열티 | 제품별 평생 총매출 100만 달러 초과분의 5% |
| 원작 로열티 | 협상 (계약금 + 매출 비율 로열티가 일반적) |
