# MVP

## 목적
- 창업을 결심하는 시점에 만들어 창업계획서와 함께 제출, 초기 자본 확보
- 판권 문의 자료로도 재사용 ([[02 IP·판권]])

## 원칙
- 심사·발표용은 오리지널 팩으로
- 겜바바 팩 버전은 판권 협상용 비공개 빌드로만

## 범위 초안
- 마을 1곳 → 미궁 1개 층 원정 → 보스 1 → 귀환 → 성장(정수 흡수·레벨업)
- 플레이 10~15분 + 1~2분 영상
- 넣을 것: 그리드 전투, 속도 기반 턴 순서, 정수 흡수·슬롯, 기본 장비, HD-2D 룩이 완성된 구역 1곳
- 뺄 것: 경매장, 클랜, 부대 전투, 항해, 넘버즈

## 보여줘야 할 것
- 심사: 실제로 돌아가는지, 재미있는지, 2인 팀이 끝까지 만들 수 있는 파이프라인인지
- 원작사: 원작 세계를 존중하며 옮겼는지, 양산형과 품질이 다른지
