# 기획 허브

웹소설 IP로 HD-2D 전술 RPG를 만드는 장기 프로젝트의 시작점. 정해진 것은 결정 로그에, 안 정해진 것은 열린 질문에 모은다.

## 한 줄 요약
『게임 속 바바리안으로 살아남기』(겜바바)를 주인공 시점으로 따라가는 HD-2D 그리드 전술 RPG. 시스템은 IP 없이 돌아가게 만들고, 겜바바 요소는 판권을 확보한 뒤 데이터로 입힌다.

## 기본값
- 팀: 2명(나 + 친구), 둘 다 개발자. 취미로 하는 장기 프로젝트
- 일정: 2026~2027 기획·아트 방향·파이프라인 실험 → 2028년부터 본격 개발. 기한 없음
- 엔진: Unreal Engine 5 (세부 버전은 개발 시작 때)
- 플랫폼·판매: PC(Steam) 패키지, 게임 내 추가 BM 없음
- 장비: 집 RTX 4060 Ti, 연구실 RTX 5070 Ti, 노트북 교체 예정(맥북 프로 램 32GB 이상)
- 도구: 문서 Obsidian(이 폴더, 친구와 git으로 공유) / 시각화 Miro / 일정 Google Calendar

## 문서 지도
- [[01 회사·사업]]: 회사 컨셉, 타깃 IP 기준, 수익 구조, 계획서 수정 메모
- [[02 IP·판권]]: 겜바바 현황, 권리 구조, 판권 전략과 공개 원칙
- [[03 게임 개요]]: 컨셉, 3층 구조, 핵심 루프, 1편 범위
	- [[03-1 전투]]: 그리드 전술, 턴 순서, 출전 인원, 자동 전투
	- [[03-2 성장·아이템]]: 레벨, 스탯, 정수, 넘버즈, 장비, 경제
	- [[03-2a 넘버즈 목록]]: 넘버즈 카탈로그, 게임 시스템으로 옮기는 방법
	- [[03-3 세계·미궁·스토리]]: 미궁 규칙, 원정 구조, 마을, 스토리 매핑
- [[04 MVP]]: 창업을 결심할 때 만들 시제품
- [[05 언리얼 기술]]: 코드 구조, 데이터 구조, 버전 관리, 학습 자료
- [[06 아트·머티리얼]]: HD-2D 룩, 에셋 파이프라인, 리서치 큐
- 이전 자료: [[Unreal Engine(HD-2D)]] (2025 설정 초안, 정리 대상), [[Unreal Engine Main]] (언리얼 팁)
