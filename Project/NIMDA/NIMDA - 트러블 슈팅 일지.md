#### 트러블 슈팅
1. DB migration : DB migration은 데이터베이스의 컬럼 구조 및 내부 데이터 정보를 변경하는 과정을 의미. 이때 다음과 같은 문제가 발생 가능함.
	1. jpa ddl-auto를 통해 데이터베이스 구조 및 정보 변경 : 데이터의 일관성을 해칠 수도 있고, 혹시 모를 보안공격을 통해 데이터에 영향을 미칠 경우 등의 심각한 문제를 발생시킬 수 있음 (기존 데이터의 일관성을 해칠 수 있음)
	2. 버전 관리 : 데이터가 변경될 때, 변경된 내용들이 문제를 야기할 수 있고, 개발자는 이전 버전으로 백업해야 하는 경우가 발생할 수도 있음. 따라서 git처럼 db의 버전을 관리해야 함. (복구를 보다 쉽게 하기 위함)
2. flyway : 위 db 마이그레이션을 제공하는 spring boot의 툴 중 하나로, Liquibase도 존재하지만, 비교적 학습 난이도가 낮은 flyway를 선택한 것으로 추정됨(liquibase는 보다 복잡한 시나리오에 맞춘 기능들을 다양하게 제공하기 때문)
