# 2주차

#### 고급 Simulation
- 완전 탐색 : 가능한 모든 방식을 탐색하는 방법, 두 가지 방법 존재
	- 다중 반복문
	- 재귀(브루트 포스)
- DP : 큰 문제를 작은 문제들로 쪼개어 차례대로 해결해나가는 방법으로, 주로 점화식을 설계함. 이때 점화식을 통해 해결하는 방식으로는 두 가지 방법 존재
	- for와 같은 반복문 : tabulation(95%의 dp문제 해결 가능, 초기 조건을 배열에 초기화하고, 이를 반복문을 통해 종료 조건 전까지의 배열 값을 점화식으로 채워넣음, 바텀업 방식)
	- 재귀 함수 : 재귀함수는 종료 조건으로 초기 조건을 넣고, 종료 조건이 아닌 입력에 대해서는 점화식으로 유도, 이때 발생하는 중복된 계산은 memoization(해당 입력에 대한 값을 배열에 저장, 모든 dp문제 해결 가능, 탑다운 방식, treedp/graphdp와 같은 방식에서만 tabulation에 비해 편함) -> (메모 확인 -> 종료 조건 -> 재귀 호출 -> 메모 갱식의 순서로 재귀 함수 호출)
